一、项目背景与目标
─────────────────────────────────
以 i.MX6ULL-Pro 为核心，"Camera + 车载终端" 为场景，面向实习岗位的嵌入式
Linux 综合练兵项目。
我的策略（务实版）：
  - 不重复造轮子 — 内核中已有的复杂驱动 (V4L2、OV5640、USB Net) 直接拿来使用。
  - 自己写简单模块 — GPIO 按键驱动、应用层采集/编码/上传逻辑，这些是面试常考
    且能体现能力的地方。
  - 系统已就绪 — 板子已有 Buildroot + Qt 可用，不做无谓的重构。
  - 目标不是"全自己写"，而是"能看懂、能调通、能扩展"。
================================================================================

二、硬件平台 — 韦东山 i.MX6ULL-Pro
───────────────────────────────────────────────
关键特性：

  CPU: NXP i.MX6ULL, ARM Cortex-A7 @ 528MHz
  RAM: 512MB DDR3L（韦东山 Pro 版）
  Storage: 8GB eMMC + MicroSD 卡槽
  显示: 7" LCD (RGB565, 电容触摸)
  Camera: CSI 接口 (OV5640) / USB UVC 摄像头
  网络: 100M Ethernet + AP6212 WiFi/BT (SDIO)
  4G: Mini-PCIe 接口 (EC200T 等)
  GPS: UART 接口 (NEO-6M / Ublox)
  USB: 1x OTG, 1x HOST
  UART: 调试串口 + 若干扩展
  SPI/I2C/GPIO: 丰富引出

确认的当前状态：
  ? 板子已烧录 Buildroot 系统
  ? 内核版本 4.9.88
  ? 系统自带 Qt 库
  ? 基础 BSP (U-Boot, kernel, dtb) 已就绪

四、软件架构图
─────────────────

┌─────────────────────────────────────────────────────┐
│                    main.c                            │
│  init_all → key_manager_task → 按键事件分发          │
│  on_preview_frame (预览+录像帧回调)                   │
└────────┬────────────┬──────────────┬─────────────────┘
         │            │              │
    ┌────▼────┐ ┌────▼────┐  ┌──────▼──────┐
    │camera   │ │recorder │  │storage      │
    │capture  │ │AVI MJPEG│  │manager      │
    └────┬────┘ └─────────┘  └─────────────┘
         │
    ┌────▼────┐ ┌────────────┐
    │hal_cam  │ │hal_fb      │
    │(V4L2)   │ │+video_conv │
    └─────────┘ └────────────┘
         │
    ┌────▼────┐
    │USB Cam  │
    │(MJPEG)  │
    └─────────┘

数据流：
  USB Cam (MJPEG) → V4L2 DQBUF → on_preview_frame
    ├─ mjpeg_to_rgb565(libjpeg-turbo) → hal_fb_draw_rgb565 → /dev/fb0
    └─ recorder_write_frame() → AVI 文件（原帧直接打包，无需编码）

按键：
  GPIO 中断 → key_manager 策略 → on_key_event → 拍照/录像/退出

存储：
  storage_manager 统一管理 SD 卡 photo/ 和 video/ 目录
  拍照 → storage_save_photo() (JPEG 帧直写)
  录像 → storage_alloc_path() → recorder_start() → recorder_stop()

七、注意事项与建议
─────────────────────

  1. MJPEG 模式是主线 — 摄像头默认 MJPEG 源，节省 USB 带宽。
     libjpeg-turbo 利用 NEON 加速解码，640x480@15fps 可行。
  2. 录像时 MJPEG 帧直接打包 AVI — 无需软件编码，降低 CPU 开销。
  3. USB 摄像头优先用 /dev/video1（内置 CSI 占用 video0）。
  4. GPS 模块 → 先用 USB 转串口在 PC 上验证 NMEA 数据格式，
     再连到板子 UART。
  5. 4G 模块 → 先内网测试(以太网 + 本地 Mosquitto)，
     4G 拨号可以复用社区脚本。
  6. 驱动部分面试重点 → GPIO 按键驱动 (自己写的)、设备树、
     V4L2 ioctl 流程、platform_driver 匹配机制。
